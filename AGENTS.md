# Project Rules - VATEK Frontend Internship (React Track)

- Stack: TypeScript (strict mode), React 19, Vite, Vitest, TailwindCSS.
- Package Manager: pnpm ONLY.
- TypeScript: STRICT mode enabled. NEVER use `any` (use `unknown` + narrowing or generics).
- React: Never use array index as key. Never use `useEffect` for derived state.
- Testing: Every utility function and custom hook must have unit tests in Vitest.
